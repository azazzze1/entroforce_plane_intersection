# Задание на стажировку — Пересечение триангулированной поверхности с горизонтальной плоскостью
## Задание
Дана триангулированная трёхмерная поверхность, в которой z-координата является функцией x- и y-координат. Требуется написать программу, которая вычисляет пересечение этой поверхности с горизонтальной плоскостью заданной высоты.

**Требования к выходным данным:**
- Пересечение выдаётся в виде замкнутых ломаных
- Точки поверхности **ниже** плоскости должны лежать **слева** по ходу направления ломаной
- Точки **выше или на** плоскости — **справа**
- Вырожденные фрагменты (точки/рёбра, где вся окрестность строго выше или ниже) должны удаляться
- Незамкнутых линий в результате остаться не должно

## Сборка проекта
Зависимости: `CMake ≥ 3.16`, `CGAL ≥ 5.0`, компилятор с поддержкой C++17.

Выполните команды из корня проекта:
```bash
sudo ./run.sh
```

В папке `build` соберётся исполняемый файл `intersection` и запустится.

## Использование

### Генерация тестовых данных
Перед запуском основного приложения сгенерируйте входной файл:
```bash
cd ../meshGenerator
python meshGenerator.py mesh.txt
```
Файл `mesh.txt` содержит:
- Строка 1: `N M` (число точек, число полигонов-ограничений)
- Следующие `N` строк: `x y z` координаты вершин
- Следующие `M` блоков: длина полигона + индексы вершин (внешний контур + дырки)

> [!NOTE]
> Генератор создаёт поверхность с «плато» (область с постоянным Z=2.5) и двумя отверстиями для тестирования краевых случаев.

#### Запуск основного приложения
```bash
cd ../build
./intersection [filename] [height]
```

Программа поддерживает два аргумента командной строки:
- `filename` — путь к `mesh.txt` (по умолчанию `../meshGenerator/mesh.txt`)
- `height` — высота плоскости сечения `Z` (по умолчанию `2.5`)

**Примеры запуска:**
```bash
# Использование значений по умолчанию
./intersection

# Указать только файл
./intersection data/custom_mesh.txt

# Указать файл и высоту среза
./intersection data/custom_mesh.txt 3.7

# Вывод справки
./intersection --help
```

### Выходные файлы
После выполнения в `../meshGenerator/` создаются:
| Файл | Описание |
|------|----------|
| `contours_final.txt` | Замкнутые контуры сечения (блоки координат `x y`, разделённые пустой строкой) |

### Визуализация результата
```bash
cd ../meshGenerator
python vizualizator.py mesh.txt -z 2.5 -c contours_final.txt -o result.png
```
